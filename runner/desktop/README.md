# Desktop-Runner

Der Runner läuft im angemeldeten Benutzerkonto mit dessen Rechten. Agenten und Projektbefehle können lokal auf dessen Dateien zugreifen; nur auf einem vertrauenswürdigen Rechner und mit passenden GitHub-Rechten verwenden. Bei Standby, Stromausfall oder Netzwerkverlust ist eine sofortige Übergabe nicht garantiert; die Server-Lease gibt verwaiste Aufträge später frei. Nicht übertragene lokale Änderungen können verloren gehen.

Voraussetzungen: vollständiges Repository klonen, Node.js ab 24, npm, git und GitHub CLI (`gh`) installieren und `gh auth login` ausführen. Agent-CLIs installieren. `runner.desktop.example.json` kopieren, Platzhalter durch **absolute** Pfade im Benutzerverzeichnis ersetzen, URL und API-Key eintragen und die Datei vor Zugriff durch andere Benutzer schützen. Alternativ `ATRIUM_URL` und `ATRIUM_API_KEY` als Umgebungsvariablen setzen. Optional den Runner-Namen als zweiten Parameter bzw. `RUNNER_NAME` angeben. Die Installation führt `npm ci` und den Build aus; Repository und Node-Pfad müssen danach bestehen bleiben.

- **Linux:** `runner/desktop/install-linux.sh /pfad/config.json [name]`. Benötigt systemd und eine aktive User-Session. Logs: `journalctl --user -u atrium-aidev-runner.service -f`. Entfernen: `runner/desktop/uninstall-linux.sh`. Optional ermöglicht `loginctl enable-linger` Betrieb nach der Abmeldung; je nach System sind dafür zusätzliche Rechte nötig.
- **macOS:** `runner/desktop/install-macos.sh /pfad/config.json [name]` in einer angemeldeten grafischen Sitzung ausführen. Logs: `~/Library/Logs/atrium-aidev-runner/`. Entfernen: `runner/desktop/uninstall-macos.sh`.
- **Windows:** `runner/desktop/install-windows.ps1 -Config C:\pfad\config.json [-Name name]` in PowerShell als angemeldeter Benutzer ausführen. Logs: `%LOCALAPPDATA%\atrium-aidev-runner\`. Entfernen: `runner/desktop/uninstall-windows.ps1`. `node-pty` ist optional; ohne das native Paket stehen Terminals nicht zur Verfügung. Die Aufgabenplanung startet beim Anmelden ohne Administratorrechte; beim Abmelden kann Windows den Prozess vor Abschluss der Übergabe beenden.

Die Skripte geben den Pfad zur geschützten installierten Konfiguration aus. Im Verzeichnis `runner` Konten mit `node dist/main.js login <konto> --config <datei>` anmelden und mit `node dist/main.js probe --config <datei>` prüfen. Unter Linux dazu `ATRIUM_URL` und `ATRIUM_API_KEY` in der Shell setzen, da der Dienst diese getrennt speichert. Anschließend den Runner in Atrium freigeben. Die Deinstallation belässt Konfiguration, Zugangsdaten, Arbeitsdaten und Logs; bei Bedarf manuell löschen. Eine erneute Installation aktualisiert Dienst und Konfiguration.
